# Raghav Agrawal — Resume Website

Personal resume website, built for the IIMBx Website Development course.

- **Live site:** https://raghavmanojagrawal-lgtm.github.io/raghav-agrawal-resume/
- `index.html` — current version, styled with CSS (CSS module assignment)
- `css/styles.css` — all styling: fonts, colour palette, navigation bar, cards, timeline, responsive rules
- `v1-html-only.html` — the original unstyled version from the HTML module, kept for comparison

## What changed in the CSS module

- Google Fonts: Poppins (headings) + Lora (body)
- Consistent colour palette via CSS variables (teal accent, off-white background, dark ink)
- Sticky navigation bar built with flexbox
- Two-column hero with an absolutely-positioned badge
- Skills and Projects as card grids (CSS grid, hover effect)
- Experience as a vertical timeline (relative/absolute positioning with `::before`)
- Element, class and ID selectors used deliberately; responsive layout below 760 px

Open `index.html` in a browser to view locally.
